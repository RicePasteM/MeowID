# ICW five-cat sample

This directory contains a one-time random sample of five identities from the
ICW test split. The sample was drawn from identities with exactly six JPEG
images so that every cat has the same registration and query protocol.

For each identity:

- `000000.jpg` is the query image.
- `000001.jpg` through `000005.jpg` form the registration gallery.

The included identities are `00001380`, `00011562`, `00013205`, `00015658`,
and `00019289`. The JPEG files are copied without transformation. They are
included only to exercise the repository's five-identity quick start; consult
the ICW dataset release terms before reusing them elsewhere.
